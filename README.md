# OSINT Recon

Настольное приложение для разведки по домену и организации: субдомены, IP, порты, находки, юрлица РФ, утечки, почта и DNS.

## Установка

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1
```

Скрипт копирует приложение в `%USERPROFILE%\OSINT Recon`, ставит зависимости в отдельное окружение и создаёт ярлыки на рабочем столе и в меню «Пуск». Повторный запуск обновляет установленную версию, история и настройки сохраняются.

Окно открывается через WebView2 (есть в Windows 10/11). Если WebView2 недоступен, приложение откроется в Edge в режиме приложения.

## Что собирается

**Пассивно, без ключей:** crt.sh, Cert Spotter, HackerTarget, AlienVault OTX, urlscan.io, Web Archive, RapidDNS, AnubisDB, subdomain.center, DNSRepo, Common Crawl.

**С ключами** (бесплатные тарифы, вводятся в «Настройках»): VirusTotal, SecurityTrails, Shodan, Netlas, Chaos, FullHunt, BeVigil, WhoisXML, а также ключи OTX и urlscan для снятия лимитов.

**DNS:** записи корня, wildcard, перебор ~450 префиксов и мутаций найденных имён, резолв всех имён, CNAME-цепочки, висячие CNAME и захват поддоменов (67 сервисов, включая Yandex Cloud, Selectel, VK Cloud, Tilda), SPF/DMARC/DKIM/MTA-STS, попытка AXFR, сервисы из TXT-верификаций.

**IP и сеть:** страна, провайдер, AS (ip-api, RDAP), порты и CVE из Shodan InternetDB, собственные AS и префиксы организации (RIPEstat).

**Организация РФ:** ЕГРЮЛ, ГИР БО ФНС, Федресурс, связанные юрлица. Привязка по ИНН из подсказки, whois или реквизитов на сайте (ИНН и ОГРН проверяются по контрольной сумме), иначе — кандидаты по названию домена.

**Утечки:** статистика Hudson Rock по логам инфостилеров (сотрудники, пользователи, адреса входа).

**Активные проверки** (флажок, по умолчанию выключены): HTTP(S) с определением ~100 технологий и панелей, TLS-сертификаты (срок, издатель, SAN → новые имена), TCP-порты 66 типовых сервисов. Используйте только для своих ресурсов или с разрешения владельца.

## Находки и отчёты

Вкладка «Находки» собирает риски с оценкой критичности и рекомендацией: AXFR, захват поддоменов, открытые СУБД/RDP/SMB, CVE, панели администрирования, VPN-шлюзы, слабая защита почты, истекающие домен и сертификаты, утечки учёток, тестовые окружения снаружи.

Экспорт: отчёт HTML (печать в PDF из браузера), Excel с листами по разделам, JSON, CSV, списки живых хостов и IP в .txt.

## Разработка

```powershell
& "$env:USERPROFILE\OSINT Recon\venv\Scripts\python.exe" -m uvicorn osint_recon.main:app --port 8766
```

Данные по умолчанию лежат в `data\` рядом с кодом; путь меняется переменной `OSINT_DATA_DIR`.
